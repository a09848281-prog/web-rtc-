## 未実装 / 制限付き
- FCMはFirebase禁止のため使用しない。GAS短周期ポーリングで自動接続要求を維持する。
- GASポーリングはプッシュ通知ではない。5秒間隔では1台を24時間待機させると約17,280回/日の要求になる。Apps ScriptとSheetsの実行状況・割当を確認しながら利用する。
- TURNサーバーと安全なTURN資格情報配布UIは未提供。現在はSTUN中心で、一部ネットワークではP2P接続できない。
- CPU負荷は正確に取得できず「取得不可」。WebRTCのRTT・packet lossに基づく詳細な連続画質制御は未完了。
- 暗闇検知はWebの受信映像の平均輝度ベース。Androidのナイトビジョン機能はない。
- Web側の管理者ログイン/認証は未実装。公開Pagesにアクセスできる人は登録コード発行・端末一覧表示・指令送信が可能。信頼できる個人利用の範囲に限定する。
